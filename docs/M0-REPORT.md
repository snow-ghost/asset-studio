# Отчёт по вехе M0 — каркас

**Закрыта:** 2026-09-10 · **Спека:** `specs/000-scaffold` (Closed) · **ADR:** 0001, 0002

## Что сделано

Каркас студии (2026-09-09): хранение ассетов, CRUD, манифест, вьюпорт в метрах, placeholder на каждый
вид, экспорт GLB/PNG, список и повторное открытие. На следующий день — долг перед контрактом `AGENTS.md`
(раздел 10): ретроспективная спека с 13 критериями, приёмка godog, разнос обоих концов по слоям
`domain → app → adapters`, машинная проверка границ, генератор трассируемости, Vitest и Playwright,
два ADR.

## Что нашла спека

Ретроспективная спека должна была позеленеть сразу. Вместо этого:

- **Формат нагрузки не проверялся.** `format` шёл в имя файла `<id>.<format>`; значение `glb/../../x`
  записывало файл за каталог данных. Закрыто: множество форматов закрыто (`glb`, `gltf`, `png`).
- **Пустой манифест отдавал `null`.** Клиент wowd, делающий `assets.find(...)`, упал бы. Закрыто: список
  всегда инициализирован (теперь — в чистой функции `domain.BuildManifest`).
- **Новый ассет без нагрузки принимался** и оставлял метаданные, указывающие на несуществующий файл.
  Закрыто правилом в `app.Save`, критерий REQ-000-6 расширен.
- **База API в сборке была прибита к `localhost:8099`**, что ломало режим одного процесса на любом другом
  порту. Закрыто: в сборке — тот же origin; проверяется REQ-000-13.

Все четыре нашлись на границе «правило ↔ инфраструктура» — там, где правило жило не в своём слое.
Это и есть аргумент за слои для инструмента такого размера (ADR-0001).

## Долг, названный честно

| Долг | Почему так | Когда |
|---|---|---|
| Сервер не проверяет соответствие «формат ↔ вид» (текстура только `png`, модели только `glb`/`gltf`); держит UI | Первый сценарий, где это важно, появится с импортом glTF или загрузкой PNG | M1 или M2 |
| Пересохранение загруженной текстуры заново рисует процедурный холст, а не пересохраняет PNG | В M0 у загруженной текстуры нет исходника; редактирование текстур — отдельная веха | M2 |
| Бандл фронтенда ≈500 КБ одним чанком (three.js) | Ленивая загрузка импортёра — после замера, когда он появится (раздел 5 контракта: не оптимизировать без замера) | M1 |
| Инвариант 8 (оригинальный IP) не проверяется машиной; в wowd есть `tools/ip-lint` | Пока в репозитории нет ни одного имени контента; линтер имеет смысл с первым ассетом | M1 |
| Нет CI: проверки запускаются руками через `make` | Репозиторий открыт 2026-09-10; workflow GitHub Actions с `make check lint test test-web trace` — отдельная маленькая задача | до M1 |
| `make e2e` требует Go и установленных браузеров Playwright | Цена честного браузерного теста; юниты и приёмка от этого не зависят | — |
